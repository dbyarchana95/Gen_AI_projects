## What is Artificial Intelligence (AI)?

Artificial Intelligence (AI) is the field of computer science that enables machines to perform tasks that normally require human intelligence.

These tasks include:

- Learning from data
- Understanding language
- Recognizing images
- Making decisions
- Solving problems
- Generating content

AI does **not think like humans**. Instead, it identifies patterns from data and predicts the most appropriate output.

## What is Prompt Engineering?

Prompt Engineering is the skill of writing clear and structured instructions so that AI produces better responses.

A better prompt generally leads to a better result.

Think of AI as an intelligent assistant—the clearer your instructions, the better it performs.

---

## Components of a Good Prompt

A strong prompt usually contains:

## Role

Tell AI who it should act as.

Example:

```
Act as a Software Tester.
```

---

## Task

Clearly describe what needs to be done.

Example:

```
Generate 20 test cases.
```

---

## Context

Provide background information.

Example:

```
The application is an e-commerce website.
```

---

## Constraints

Mention limitations.

Example:

```
Use simple language.
Limit to 300 words.
```

---

## Output Format

Specify how you want the answer.

Examples:

- Markdown
- Table
- JSON
- Bullet points
- CSV

---

## Prompt Formula

```
Role
+ Task
+ Context
+ Constraints
+ Output Format
```

---

## Example

❌ Weak Prompt

```
Write about AI.
```

---

✅ Better Prompt

```
Act as an AI instructor.

Explain Artificial Intelligence for beginners using simple language.

Include:
- Definition
- Examples
- Advantages
- Limitations

Format the answer in Markdown with headings.
```

## Prompting Techniques

### Zero-Shot Prompting

No examples are provided.

Example:

```
Summarize this article.
```

---

### One-Shot Prompting

Provide one example.

```
Example:

Input:
Hello

Output:
Greeting

Now classify:

Thank You
```

---

### Few-Shot Prompting

Provide multiple examples before asking AI.

Useful for improving consistency.

---

### Role Prompting

Assign a role.

Example:

```
You are a Data Analyst.
```

---

### Step-by-Step Prompting

Ask AI to solve problems step by step.

Example:

```
Explain each step before giving the final answer.
```

---

## Best Practices
 - Be specific 
 - Give context 
 - Mention audience 
 - Specify output format 
 - Break complex tasks into smaller prompts 
 - Review AI-generated responses

---

## Common Mistakes

- Very short prompts
- Missing context
- Asking multiple unrelated questions together
- Not specifying output format
- Blindly trusting AI responses
